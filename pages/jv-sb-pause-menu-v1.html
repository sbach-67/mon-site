JV_SB Pause Menu V1

Pause menu personnalisé et stylisé pour votre serveur ESX.

Compatibilité : ESX Support : Discord JV.SB Accès : Tebex

Installation

Importez la ressource et démarrez-la dans server.cfg.

Configuration

Modifiez les liens, textes et sections pour correspondre à votre serveur.

Configuration (aperçu)

Voir le fichier config.lua 
Config = {}

-- ============================================
-- CONFIGURATION DU LOGO
-- ============================================
-- Lien de votre logo (vous pouvez le modifier ici)
Config.LogoURL = "https://zupimages.net/up/25/47/f2eb.png"

-- ============================================
-- CONFIGURATION DE LA BARRE AUDIO
-- ============================================
-- Activer ou désactiver la barre audio dans le menu pause
-- true = activé, false = désactivé
Config.EnableAudioBar = true

-- ============================================
-- CONFIGURATION DES MUSIQUES
-- ============================================
-- Choisir quelles musiques jouer
-- Options disponibles :
--   "all" = jouer toutes les musiques (1, 2, 3)
--   "1" = jouer uniquement la musique 1
--   "2" = jouer uniquement la musique 2
--   "3" = jouer uniquement la musique 3
--   "1,2" = jouer les musiques 1 et 2
--   "1,3" = jouer les musiques 1 et 3
--   "2,3" = jouer les musiques 2 et 3
--   "1,2,3" = jouer toutes les musiques (équivalent à "all")
Config.MusicTracks = "all"  -- Par défaut, toutes les musiques sont jouées

-- ============================================
-- CONFIGURATION DE LA SECTION INFORMATION
-- ============================================
-- Texte personnalisé affiché dans la section INFORMATION du menu pause
-- Vous pouvez utiliser des emojis et du HTML basique
Config.InfoText = "🚀 BOUTIQUE JV_SB CRÉATION : DES MAPS ET SCRIPTS RÉALISTES QUI RÉVOLUTIONNENT VOS PROJETS Voulez-vous faire passer votre serveur FiveM, votre jeu de rôle ou votre communauté de jeu au niveau supérieur ? Vos joueurs méritent une expérience unique, fluide et mémorable... et voici la solution."

-- CONFIGURATION DU LIEN DISCORD
