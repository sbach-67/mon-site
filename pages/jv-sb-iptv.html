JV.SB IPTV

Documentation complète pour l’installation et la configuration du script IPTV JV.SB.

Compatibilité : ESX Support : Discord JV.SB Accès : Tebex

Installation

Déposez la ressource dans votre dossier resources, puis ajoutez la ligne dans votre server.cfg.

Configuration

Ouvrez le fichier de configuration et adaptez les paramètres selon votre serveur (langue, accès, permissions).

Configuration (aperçu)

Voir le fichier config.lua

---   - heading : Orientation de l'écran (en degrés)
---   - scale : Dimensions de l'écran {largeur, hauteur}
---   - distance : Distance maximale d'interaction (en mètres)
---   - label : Nom affiché pour cet écran (optionnel)
--- @type table

-- ═══════════════════════════════════════════════════════════════════════════════
-- 🔐 CONFIGURATION DES PERMISSIONS
-- ═══════════════════════════════════════════════════════════════════════════════

--- Autoriser les administrateurs à utiliser les écrans TV
--- Si false, même les admins ne pourront pas utiliser les écrans
--- @type boolean
Config.AllowAdmins = true

--- Liste des groupes admin reconnus pour les permissions
--- Le script vérifiera si le joueur appartient à l'un de ces groupes
--- @type table
Config.AdminGroups = {
    "admin",
    "superadmin",
    "mod",
    "moderator",
    "administrator",
    "super_admin",
    "god",
    "founder"
}

--- Exiger un job spécifique pour utiliser les écrans TV
--- Si false : Seuls les admins pourront utiliser (si Config.AllowAdmins = true)
--- Si true : Les admins ET les jobs autorisés dans Config.AllowedJobs pourront utiliser
--- @type boolean
Config.RequireJob = false

--- Liste des jobs autorisés à utiliser les écrans TV
--- Utilisé uniquement si Config.RequireJob = true
--- Format : Liste des noms de jobs (ex: "police", "ambulance")
--- @type table
Config.AllowedJobs = {
    -- Exemples :
    -- "police",
    -- "ambulance",
    -- "admin"
}

-- ═══════════════════════════════════════════════════════════════════════════════
-- 📄 CONFIGURATION M3U
-- ═══════════════════════════════════════════════════════════════════════════════

--- Activer l'onglet "Fichier M3U" dans le menu IPTV
--- Si true : L'onglet M3U sera visible et utilisable
--- Si false : L'onglet M3U sera masqué
--- @type boolean
Config.EnableM3U = false

-- ═══════════════════════════════════════════════════════════════════════════════
-- 🌐 CONFIGURATION CLOUDFLARE / PROXY
-- ═══════════════════════════════════════════════════════════════════════════════

--- URL d'un proxy HTTP optionnel pour contourner Cloudflare
--- Si votre serveur IPTV est protégé par Cloudflare, vous pouvez utiliser un proxy
--- Format: "http://proxy.example.com:8080" ou nil pour désactiver
--- @type string|nil
Config.ProxyURL = nil

--- Activer le mode de contournement Cloudflare avancé
--- Essaie différentes techniques pour contourner Cloudflare (peut être plus lent)
--- @type boolean
Config.AdvancedCloudflareBypass = true

-- ═══════════════════════════════════════════════════════════════════════════════
