JV_SB_HandlingPro

Réglages handling avancés pour améliorer le comportement des véhicules.

Compatibilité : ESX Support : Discord JV.SB Accès : Tebex

Installation

Importez la ressource et démarrez-la dans server.cfg.

Configuration

Appliquez les profils handling via la config fournie.

Configuration (aperçu)

Voir le fichier config.lua
