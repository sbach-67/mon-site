JV_SB Guetteur

Système de guetteur avec alertes et détection dynamique.

Compatibilité : ESX Support : Discord JV.SB Accès : Tebex

Installation

Déposez la ressource dans resources puis démarrez-la.

Configuration

Réglez les zones, déclencheurs et alertes dans la config.

Configuration (aperçu)

Voir le fichier config.lua 
Config = {}

-- Choix du système de notification : 'ox' ou 'okok'
Config.NotificationSystem = 'okok'  -- Change en 'okok' si tu veux utiliser okokNotify

-- Liste des jobs détectables
Config.AllowedJobs = {
    'police',
    'sheriff',
    'pompier'
}
