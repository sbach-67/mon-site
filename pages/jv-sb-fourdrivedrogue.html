JV.SB_FourDriveDrogue

Documentation pour la gestion FourDrive et activités illégales côté ESX.

Compatibilité : ESX Support : Discord JV.SB Accès : Tebex

Installation

Ajoutez la ressource dans resources et démarrez-la via server.cfg.

Configuration

Paramétrez les zones, items et permissions selon votre gameplay.

-- ============================================
-- 📦 CONFIGURATION DES DROGUES
-- ============================================

-- Liste des drogues que les joueurs peuvent vendre
-- Structure:
--   - label: string → Nom affiché dans le menu
--   - value: string → Nom de l'item dans l'inventaire
--   - price: table → Prix min et max en argent sale (€)
Config.Drugs = {
    { label = "Weed", value = "weed_package", price = {min = 10, max = 25} },
    { label = "Meth", value = "meth_bag", price = {min = 40, max = 70} },
    { label = "Crack", value = "crack", price = {min = 60, max = 90} },
    { label = "Heroin", value = "heroin", price = {min = 100, max = 150} },
    { label = "Coke", value = "coke_figure", price = {min = 80, max = 120} }
}

-- ============================================
-- ⚙️ PARAMÈTRES GÉNÉRAUX
-- ============================================

-- Système de notifications à utiliser
-- Options: 'jv_sb_lib' ou 'ox_lib'
Config.NotificationSystem = 'jv_sb_lib'

-- Intervalle entre chaque proposition de vente (en millisecondes)
Config.SellCooldown = 3000

-- Distance maximale pour quitter la chaise et annuler la vente (en mètres)
Config.MaxDistance = 2.5

-- Heure minimum pour commencer à dealer (0-23)
-- Définir à 0 pour autoriser 24/24
Config.DealStartHour = 12

-- Nombre minimum de policiers en service requis pour dealer
Config.MinPolice = 0

-- Jobs de police reconnus par le script
Config.PoliceJobs = {
    'police',
    'police_nationale',
    'gendarmerie'
}
